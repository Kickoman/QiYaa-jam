# `web/` — веб-гость

Страница, которую гость открывает по ссылке `https://<сервер>/j/<roomId>#<joinSecret>`: войти с
именем, видеть, что играет и что в очереди, искать и добавлять треки. Preact + Vite + TypeScript,
тёмная тема и шрифты QiYaa для Android, русский и английский. Сервер отдаёт собранную папку
`web/dist` (`WEB_ROOT`). Готовы каркас (#13), вход и комната (#14), поиск и добавление (#15); крайние
случаи и тест в браузере — Kickoman/QiYaa-jam#16.

| Файл | Что там |

| `src/app.tsx` | `App` — шапка с языком; экран по фазе сессии; баннеры связи и хозяина; уведомления |
| `src/session.ts` | `JamSession` — вход, состояние комнаты, запросы; без Preact, тестируется с поддельным сокетом |
| `src/format.ts` | `coverUrl`, `formatTime`, `positionAt` — обложки, время, позиция по серверным часам |
| `src/add-state.ts` | `addButton` — состояние кнопки «+» у результата поиска |

| `src/app.css` | Стили экранов |

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev -w web` | Vite на :5173 с прокси `/ws` на :8090 |
| `npm run build -w web` | Сборка в `web/dist` |
| `npm run check -w web` | Типы, тесты, сборка, бюджет |

Для живой разработки с сервером и имитатором хозяина:

```bash
PUBLIC_URL=http://localhost:5173 npm run dev     # сервер на :8090 с этим адресом в ссылке и Origin
npm run dev -w web                               # в соседнем терминале
```

`PUBLIC_URL` нужен, потому что сервер пускает браузер только со своего `Origin` (ROOM-59).

## Токены

Цвета и стили текста перенесены из `QiYaa-android/app/src/main/java/io/github/kickoman/qiyaa/ui/theme/`
(`Color.kt`, `Type.kt`), акцент — классический зелёный. Имена — те же, в kebab-case
(`--text-secondary`, `--accent-background`). Стили текста — `--caption`, `--label`, `--button`,
`--readout`, `--hint` (Plex Mono, с `letter-spacing`), `--body`, `--title` (Plex Sans). Цель касания —
`--touch` (48 px).

## Шрифты

Файлы woff2 разбиты по `unicode-range`: браузер скачивает только те, что нужны для текста на
странице. 12 файлов по 17–22 КБ. В бюджет не входят. Внешних запросов у страницы нет, кроме
обложек с `avatars.yandex.net`; `<meta name="referrer" content="no-referrer">` не даёт им узнать
адрес комнаты.

## `src/protocol/client.ts`

```ts
class JamConnection {
  constructor(options: { url; appVersion; onMessage; onStatus; onWelcome }, environment: ClientEnvironment);
  start(): void;  stop(): void;  networkBack(): void;
  send(message: ClientMessage): boolean;       // false — сейчас нет связи
  get clockOffsetMs(): number;  serverNow(): number;
}
```

- После открытия шлёт `hello`, после `welcome` — `online`, `onWelcome` (там приложение шлёт `join`).
- Смещение часов — `serverTime − сейчас` из `welcome` и каждого `state`.
- Обрыв — `offline` и переподключение через 1, 2, 4, 8, 16, 30, 30 … с; `welcome` сбрасывает счёт.
  `networkBack()` (событие `online` браузера) подключается сразу.
- `stop()` — навсегда: после `ended`, `kicked`, `update-required`.
- `ClientEnvironment` подменяется в тестах: сокет, часы и таймеры.

**Ловушки:**
- Типы сообщений импортируются из `server/src/protocol/generated/types.ts` только как типы: сборка их
  стирает, а `npm run generate` нужен для проверки типов.

## `src/session.ts`

```ts
class JamSession {
  constructor(dependencies: { link; url; appVersion; storage; environment; newParticipantId });
  view(): SessionView;                 // {phase, status, room, notice, name}
  subscribe(listener): () => void;
  start(): void;                       // сразу входит, если участник этой комнаты уже сохранён
  join(name: string): boolean;         // false — имя пустое или длиннее 24, или в ссылке нет секрета
  find(text: string): boolean;         // false — пустой или длиннее 100 символов текст, нет связи
  closeSearch(): void;  add(trackId: string): void;
  remove(itemId: string): void;  skip(itemId: string): void;
  networkBack(): void;  stop(): void;  serverNow(): number;
}
```

Фазы: `no-secret` (ссылка без `#секрета` и гость здесь впервые) → `need-name` → `joining` →
`in-room`; конечные — `refused{reason}`, `ended{reason}`, `kicked`, `update-required`: соединение
закрывается и больше не восстанавливается. Прочие отказы (`remove`, `skip`) — `notice`, их
показывает уведомление на 4 с.

- Имя обрезается по краям, пробелы внутри схлопываются, длина — 1–24 символа, как считает схема
  (код-пойнты, эмодзи — один символ).
- `participantId` (UUID v4 из `crypto.randomUUID`), имя и секрет из ссылки сохраняются на комнату после
  `joined`. После входа `#секрет` убирается из адресной строки (`history.replaceState`): ссылку с
  экрана уже не перепишешь. Сохранённый секрет нужен, чтобы войти снова после перезагрузки или обрыва.
- На одном соединении `state` со старой или той же версией пропускается; после переподключения
  первый `state` принимается как есть (протокол, раздел «State»).

**Ловушки:**
- Если `localStorage` заблокирован (приватное окно), после перезагрузки гость войдёт как новый
  участник, а без `#секрета` в адресе — не войдёт вовсе.

## Экраны

- **Вход:** «Вас позвали в джем», имя (запоминается), «Войти». Пустое имя кнопку не включает.
- **Поиск** (только у гостя, над «Сейчас играет»): по Enter, без подсказок по мере ввода — каждый поиск
  тратит запрос аккаунта хозяина. Текст обрезается и схлопывается, как на сервере. Показываются только
  результаты последнего запроса. Хозяин не в сети — поле выключено, но найденное раньше добавить можно
  (сервер берёт его из кэша, REC-01). Кнопка у результата: «+»; «…» пока ждём ответа; «Ваш, в очереди»;
  «В очереди: Имя»; «Лимит» с подсказкой, когда своих треков уже `maxPendingPerGuest`; после отказа
  снова «+» и текст причины под треком. У каждой причины протокола свой текст на обоих языках — это
  проверяет тест по `defs.schema.json`.
- **Комната:** «Сейчас играет» — обложка 400 px, название, исполнители, «Добавлено: Имя» или «Волна
  джема», прогресс по серверному времени (раз в секунду), «Пропустить» — только если хозяин разрешил
  и играет трек гостя. «Очередь» — в порядке воспроизведения, «Ваших треков: N / лимит», свои отмечены
  и убираются крестиком, закреплённые — «дальше». «Участники» — точка «в сети», метки «хозяин» и «вы».
- Вёрстка от 320 px, цели касания не меньше 48 px, длинные названия обрезаются многоточием.

Проверено в Chromium без экрана на 360 px: вход, комната с треками от гостя-скрипта, живой
прогресс, `#секрет` исчезает из адреса, поиск и добавление с состояниями кнопки. На телефоне пока не
проверялось.
