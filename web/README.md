# `web/` — веб-гость

Страница, которую гость открывает по ссылке `https://<сервер>/j/<roomId>#<joinSecret>`: войти с
именем, видеть, что играет и что в очереди, искать и добавлять треки. Preact + Vite + TypeScript,
дизайн-система QiYaa (окна со скосами, LED, пиксельный шрифт), английский и белорусский. Сервер отдаёт собранную папку
`web/dist` (`WEB_ROOT`). Kickoman/QiYaa-jam#13–#16.

| Файл | Что там |
|---|---|
| `src/main.tsx` | Точка входа: стили и `App` |
| `src/app.tsx` | `App` — шапка с языком; экран по фазе сессии; баннеры связи и хозяина; уведомления |
| `src/session.ts` | `JamSession` — вход, состояние комнаты, запросы; без Preact, тестируется с поддельным сокетом |
| `src/format.ts` | `coverUrl`, `formatTime`, `positionAt` — обложки, время, позиция по серверным часам |
| `src/listen.ts` | `Listener` — прослушивание вместе с хозяином (эксперимент): играет `nowPlaying.listenUrl` в позиции комнаты |
| `src/add-state.ts` | `addButton` — состояние кнопки «+» у результата поиска |
| `src/components/` | `JoinForm`, `SearchPanel`, `NowPlaying`, `QueueList`, `People` — только отображение; `chrome.tsx` — `Window`, `TitleButton`, `Lamp`, `Icon` дизайн-системы |
| `src/theme.css` | Токены дизайн-системы QiYaa; `@font-face` Press Start 2P и IBM Plex |
| `src/app.css` | Стили: окна, кнопки, поля, LCD, плейлист |
| `src/i18n.ts` | Тексты на английском и белорусском, выбор языка |
| `src/link.ts` | `parseJoinLink`, `socketUrl` — комната и секрет из адреса |
| `src/storage.ts` | `participantId` и имя на комнату в `localStorage` |
| `src/protocol/client.ts` | `JamConnection` — рукопожатие, смещение часов, переподключение |
| `src/fonts/` | Press Start 2P; IBM Plex Sans 400/500/600 и Mono 400/500; латиница и кириллица, OFL |
| `scripts/budget.mjs` | Проверка бюджета: до 100 КиБ gzip без шрифтов |
| `e2e/jam.spec.ts` | Playwright: сервер, имитатор хозяина и браузерные гости |

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev -w web` | Vite на :5173 с прокси `/ws` на :8090 |
| `npm run build -w web` | Сборка в `web/dist` |
| `npm run check -w web` | Типы, тесты, сборка, бюджет |
| `npm run e2e -w web` | Сборка и тесты в Chromium (один раз: `npx playwright install chromium`) |

Для живой разработки с сервером и имитатором хозяина:

```bash
PUBLIC_URL=http://localhost:5173 npm run dev     # сервер на :8090 с этим адресом в ссылке и Origin
npm run dev -w web                               # в соседнем терминале
```

`PUBLIC_URL` нужен, потому что сервер пускает браузер только со своего `Origin` (ROOM-59).

## Дизайн

Страница реализует дизайн-систему QiYaa (проект «QiYaa Design System» в claude.ai/design): токены из
её `tokens/*.css` — в `src/theme.css` с теми же именами (`--chrome-700`, `--led-500`, `--gold-500`,
`--bevel-raised`, `--screen-inset`…), компоненты повторены классами в `src/app.css`:

| В системе | Здесь |
|---|---|
| `WindowFrame`, `TitleBar`, `TitleButton` | `Window`, `TitleButton` (`chrome.tsx`); `.window`, `.title-bar`, `.title-button` |
| `Button` primary / secondary | `.btn`, `.btn-primary` |
| `Input` | `.field`, `.input` (LCD, зелёный моно) |
| `ToggleButton` | `.toggle` (EN / BE) |
| `Playlist` | `.playlist`, `.row` — зелёный на чёрном, свои треки белым |
| `LedDigits`, `Lamp` | `.digits`, `Lamp`, `.lamp` |
| `Icon` (Lucide) | `Icon` — те же пути, встроенный SVG |

Правила системы: углов нет, рамок нет — только скосы 2 px; пиксельный шрифт — заголовки, кнопки,
лампы и цифры, всегда заглавными; IBM Plex Sans — текст, Plex Mono — поля и строки плейлиста;
состояния — светлее при наведении, вдавлено при нажатии, LED-подсветка у включённого, фокус —
зелёная рамка 2 px. Кнопки заголовка нарисованы 18 px, но ловят касание на 44 px.

## Языки

Английский и белорусский. По умолчанию — белорусский, если браузер говорит `be` или `ru`, иначе
английский; выбор кнопкой EN / BE запоминается. Сохранённый раньше `ru` считается невыбранным.
Press Start 2P покрывает кириллицу (`U+0400–045F`, с `і` и `ў`).

## Шрифты

Файлы woff2 разбиты по `unicode-range`: браузер скачивает только те, что нужны для текста на
странице. 12 файлов по 7–22 КБ. В бюджет не входят. Внешних запросов у страницы нет, кроме
обложек с `avatars.yandex.net`; `<meta name="referrer" content="no-referrer">` не даёт им узнать
адрес комнаты.

## `src/protocol/client.ts`

```ts
class JamConnection {
  constructor(options: { url; appVersion; onMessage; onStatus; onWelcome }, environment: ClientEnvironment);
  start(): void;  stop(): void;  networkBack(): void;
  send(message: ClientMessage): boolean;       // false — сейчас нет связи
  get clockOffsetMs(): number;  serverNow(): number;
}
```

- После открытия шлёт `hello`, после `welcome` — `online`, `onWelcome` (там приложение шлёт `join`).
- Смещение часов — `serverTime − сейчас` из `welcome` и каждого `state`.
- Обрыв — `offline` и переподключение через 1, 2, 4, 8, 16, 30, 30 … с; `welcome` сбрасывает счёт.
  `networkBack()` (событие `online` браузера) подключается сразу.
- `stop()` — навсегда: после `ended`, `kicked`, `update-required`.
- `ClientEnvironment` подменяется в тестах: сокет, часы и таймеры.

**Ловушки:**
- Типы сообщений импортируются из `server/src/protocol/generated/types.ts` только как типы: сборка их
  стирает, а `npm run generate` нужен для проверки типов.

## `src/session.ts`

```ts
class JamSession {
  constructor(dependencies: { link; url; appVersion; storage; environment; newParticipantId });
  view(): SessionView;                 // {phase, status, room, notice, name}
  subscribe(listener): () => void;
  start(): void;                       // сразу входит, если участник этой комнаты уже сохранён
  join(name: string): boolean;         // false — имя пустое или длиннее 24, или в ссылке нет секрета
  find(text: string): boolean;         // false — пустой или длиннее 100 символов текст, нет связи
  closeSearch(): void;  add(trackId: string): void;
  remove(itemId: string): void;  skip(itemId: string): void;
  networkBack(): void;  stop(): void;  serverNow(): number;
}
```

Фазы: `no-secret` (ссылка без `#секрета` и гость здесь впервые) → `need-name` → `joining` →
`in-room`; `waiting-for-room` — сервер не знает комнату, в которой гость уже был (REC-14): вход
повторяется через 5, 10, 20, 30, 30 … с (±20 %), `rate-limited` тоже ждётся, через 10 мин —
`refused{room-not-found}`. Первый вход в незнакомую комнату отказывает сразу. Конечные — `refused{reason}`, `ended{reason}`, `kicked`, `update-required`: соединение
закрывается и больше не восстанавливается. Прочие отказы (`remove`, `skip`) — `notice`, их
показывает уведомление на 4 с.

- Имя обрезается по краям, пробелы внутри схлопываются, длина — 1–24 символа, как считает схема
  (код-пойнты, эмодзи — один символ).
- `participantId` (UUID v4 из `crypto.randomUUID`), имя и секрет из ссылки сохраняются на комнату после
  `joined`. После входа `#секрет` убирается из адресной строки (`history.replaceState`): ссылку с
  экрана уже не перепишешь. Сохранённый секрет нужен, чтобы войти снова после перезагрузки или обрыва.
- На одном соединении `state` со старой или той же версией пропускается; после переподключения
  первый `state` принимается как есть (протокол, раздел «State»).

**Ловушки:**
- Если `localStorage` заблокирован (приватное окно), после перезагрузки гость войдёт как новый
  участник, а без `#секрета` в адресе — не войдёт вовсе.

## Экраны

- **Вход:** окно «Join the jam», имя (запоминается), «Join». Пустое имя кнопку не включает.
- **Поиск** (только у гостя, над «Now playing»): по кнопке «Find» или Enter, без подсказок по мере
  ввода — каждый поиск тратит запрос аккаунта хозяина. Заголовок окна поиска прилипает к верху экрана,
  пока окно видно: в нём «свернуть / развернуть» и «очистить» результаты, так что их не нужно
  пролистывать до конца. Свернуть можно и строкой «Results for …»; новый поиск разворачивает. Текст обрезается и схлопывается, как на сервере. Показываются только
  результаты последнего запроса. Хозяин не в сети — поле выключено, но найденное раньше добавить можно
  (сервер берёт его из кэша, REC-01). Кнопка у результата: «+»; «…» пока ждём ответа; «Ваш, в очереди»;
  «В очереди: Имя»; «Лимит» с подсказкой, когда своих треков уже `maxPendingPerGuest`; после отказа
  снова «+» и текст причины под треком. У каждой причины протокола свой текст на обоих языках — это
  проверяет тест по `defs.schema.json`.
- **Комната:** «Now playing» — обложка 200 px в рамке LCD, название, исполнители, «Added by Имя» или
  лампа «Jam vibe», время LED-цифрами и полоса позиции по серверному времени (раз в секунду),
  «Skip» — только если хозяин разрешил и играет трек гостя. «Queue» — плейлист в порядке
  воспроизведения, «Yours N/лимит» в заголовке, свои белым и убираются крестиком, закреплённые —
  лампа «next». «People» — LED «в сети», лампы «host» и «you».
- **Слушать вместе (эксперимент, `spec/jam/protocol/README.md`).** Когда хозяин разрешил и прислал
  `nowPlaying.listenUrl`, под «Now playing» — кнопка «Listen here» и подсказка. По нажатию
  `Listener` играет файл хозяина (`<audio>`, ссылка ведёт прямо в хранилище Яндекса, через наш
  сервер звук не идёт) с позиции комнаты, следует за паузой и сменой трека, раз в секунду сверяется
  и перематывает, если ушёл больше чем на 2 с (`limits.md`). Пока ссылки нет (хозяин выключил,
  тишина), звук на паузе, а прослушивание не выключается. Пауза снаружи (экран блокировки,
  гарнитура, звонок) выключает прослушивание; собственные паузы и конец файла — нет. На экране
  блокировки — название, исполнители и обложка (Media Session API), кнопка паузы там тоже
  выключает прослушивание. В браузерных тестах файл подменяется `e2e/fixtures/sine440_3s.mp3`
  (синус 440 Гц из тестов QiYaa).
- Вёрстка от 320 px, цели касания не меньше 44 px, длинные названия переносятся.

## Тесты в браузере

`e2e/jam.spec.ts` поднимает сервер с собранным `web/dist` и имитатора хозяина в том же процессе и
открывает гостей в Chromium (390 px, `ru-RU`, то есть белорусский):

- два гостя входят, добавляют через поиск, оба видят очередь в порядке «по кругу»; хозяин пропадает
  и возвращается — поиск кнопкой и Enter, сворачивание результатов; баннер «Гаспадар не ў сетцы» появляется и уходит;
- плановый перезапуск сервера с файлом комнат: баннер «Няма сувязі», гость переподключается сам,
  очередь на месте;
- падение сервера (REC-14): гость видит «Сервер згубіў джэм» и ждёт; хозяин поднимает комнату из
  снимка, гость входит снова, трек на месте.

Интервалы повторов у гостя — настоящие (5 ± 1 с), поэтому третий тест идёт около 10 с.

На телефоне страница пока не проверялась: переключение Wi-Fi ↔ мобильная сеть — ручная проверка
из задачи. Баннеры на все случаи (нет связи, хозяин не в сети, джем закончен, вас удалили, вход
закрыт, ссылка устарела, сервер потерял джем) есть; тексты отказов проверяет юнит-тест.
